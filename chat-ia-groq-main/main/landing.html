 como funciona
Três passos, do arquivo ao documento.
Tudo acontece no navegador. Você decide o que vai para a análise com IA.

      

        
01
Envie as fontes
Arraste arquivos e ZIPs, cole um trecho ou informe um repositório do GitHub. PDF e DOCX também entram.

        
02
Analise
Um relatório automático mostra o mapa do projeto e padrões suspeitos. Depois escolha: visão geral, segurança, bugs, LGPD ou resumo.

        
03
Gere os documentos
README, documentação técnica, guia de uso e relatórios, em Markdown, HTML ou PDF.

 perguntas
Antes de começar.

      
Preciso de uma chave de API?
Sim. A análise com IA usa a API da Groq, que tem plano gratuito. Você cola a chave no workspace e ela fica só no seu navegador.

      
Meus arquivos são enviados para algum servidor?
A leitura e os alertas automáticos acontecem no navegador. Quando você pede uma análise com IA, apenas o trecho selecionado é enviado à Groq. Evite arquivos com segredos ou dados pessoais reais.

      
Funciona com repositório privado?
Sim, com um token do GitHub de leitura configurado em Integrações. Repositórios públicos funcionam sem token.

      
O relatório de LGPD substitui um advogado?
Não. Ele aponta riscos e lacunas para você levar a uma revisão jurídica.

      
Qual atalho abre a busca rápida?
Ctrl+K (ou ⌘K no Mac) abre a paleta de comandos dentro do workspace para ir a qualquer aba.
